Instrucciones de Uso
Clonar el repositorio:

Bash
git clone [https://github.com/tu-usuario/tu-repositorio.git](https://github.com/tu-usuario/tu-repositorio.git)
Abrir el proyecto:
Abre la carpeta contenedora en tu editor de código favorito (por ejemplo, Visual Studio Code).

Utiliza una extensión de desarrollo local como Live Server para levantar un servidor web y visualizar el archivo index.html en tiempo real en tu navegador web.

Guía de Usuario Breve:
Navegación: Utiliza la barra superior de botones (Inicio, Playlist de Alejandra, Playlist de Angel, Sugerir Cancion) para desplazarte de manera fluida entre las distintas secciones de la plataforma.

Exploración de Contenido: Consulta la tabla interactiva que detalla el top de canciones, los artistas y sus respectivos géneros musicales, acompañados de sus carátulas optimizadas con descripciones de accesibilidad.

Interactividad: La interfaz está optimizada para ofrecer una lectura rápida, cómoda y sin distracciones mientras mantienes el enfoque en tus sesiones de codificación.

💡 Reflexión Colaborativa
El desarrollo de este proyecto representó una valiosa oportunidad para integrar buenas prácticas de desarrollo web, enfocándonos especialmente en la accesibilidad (a11y) y la semántica de HTML. Incorporar atributos alt descriptivos en cada elemento gráfico y mantener una jerarquía estricta de encabezados (h1 → h2 → h3) nos permitió comprender que el diseño web moderno no solo debe ser visualmente atractivo, sino también inclusivo y navegable para tecnologías de asistencia como los lectores de pantalla.

Asimismo, el proceso de validación mediante los estándares oficiales de la W3C nos ayudó a depurar errores de sintaxis, asegurando un código limpio, robusto y preparado para futuras ampliaciones. Finalmente, una arquitectura de archivos ordenada y una documentación clara a través de este README facilitan enormemente el mantenimiento del software y reafirman que la calidad técnica es la base fundamental de una excelente experiencia de usuario.
