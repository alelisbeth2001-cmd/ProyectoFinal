Asimismo, el uso obligatorio de Pull Requests con revisiones cruzadas y la aplicación de etiquetas (v1.0) nos demostraron cómo se maneja un flujo de trabajo profesional y trazable listo para producción. En conclusión, Git no solo actúa como una herramienta de respaldo, sino como el pilar fundamental para garantizar la sincronía, el orden y el éxito en el desarrollo de software en equipo.
